# 기후가 바뀌면, 우리 마을은?

초등학교 4학년 과학 4단원 「기후 변화와 우리 생활」의 교과서 90~101쪽을 연결하는 개인용 웹앱입니다.

## 학생 탐구 기록지

각 탐구에서 오른쪽 위 **내 탐구 기록지**를 누르면 그 탐구에서 작성한 답, 관찰값, 담은 증거를 볼 수 있습니다. 답은 기록지에서도 수정할 수 있고 현재 브라우저에 자동 저장됩니다. 이름과 모둠은 선택 사항입니다.

**PDF 다운로드**는 선택한 탐구의 모든 쪽을 A4 파일 하나로 저장합니다. **PNG 다운로드**는 그림 한 장으로 저장하며, 여러 쪽이면 받을 쪽을 고릅니다. 비어 있는 답은 출력해서 손으로 쓸 수 있습니다. **전체 기록 모아 보기**에서 다섯 탐구를 함께 보거나 다른 기기로 옮길 백업 파일을 받을 수 있습니다.

## 들어 있는 탐구

1. 현상 찾기: 폭염·가뭄·홍수·폭설·한파·열대야의 실제 사진, 관측 그래프·표, CSV 내려받기, 자료의 범위와 한계 기록.
2. 우리의 행동: 쓰레기·냉장고·숲·공장·이동·전기의 두 가지 선택을 최대 120회 누적. 마을 사진에서 장소를 고르고 물건 그림을 누르거나 노란 장소로 끌어 놓으면 한 번의 행동이 쌓입니다. 장소별·행동별 횟수와 관찰 결과, 같은 시간이 흐른 두 마을을 비교할 수 있습니다.
3. 문제의 심각성: 교과서의 여섯 나라 피해 사례와 실제 촬영 자료·위성 비교 영상. 사진 확대, 촬영 시기·출처 표시, 국내 사례 조사·토의.
4. 해수면 실험: 회전·확대할 수 있는 입체 수조. 집·학교·빌딩·아파트·병원·가게의 여섯 종류를 골라 여러 개 배치. 시계탑·유리벽·십자·차양 등 다른 외형과 이름 표시. 물 높이 0~10단계, 물줄기·잔물결·반투명 물층, 수면 아래로 잠기는 건물·나무, 반복 실험 관찰값 저장. 물이 오르내리는 동안 침수 수가 변하고 목표 높이에 도달하면 관찰값을 기록할 수 있습니다.
5. 생활의 변화: 학교·농장·도로·주택의 영향 연결, 근거를 넣은 설명.

모든 메뉴는 순서를 강제하지 않고 바로 들어갈 수 있습니다. 실제 자료와 학습용 가상 장면을 구별해 표시합니다.

## 학생 사용

배포 주소 끝에 `?lesson=actions`를 붙이면 ‘02 우리의 행동’에서 바로 수업을 시작합니다.

로그인·Firebase·서버 설정이 필요 없습니다. 이름·모둠은 선택 사항입니다. 기기별 브라우저 저장소에 기록하며 교사에게 자동 전송하지 않습니다.

‘탐구 기록’에서 기록지 PNG 저장, 인쇄·PDF 저장, JSON 백업·불러오기를 사용할 수 있습니다. 기기를 바꾸거나 브라우저 데이터를 지우기 전에는 백업하세요. PNG가 지나치게 길면 인쇄·PDF를 이용하세요.

수업 도구에는 차시 이동, 모둠 토의 질문, 전체화면, 경고음이 있는 타이머가 있습니다. 타이머 소리는 사용자가 시작을 눌러야 활성화되며 브라우저의 음량 설정을 따릅니다.

## GitHub + Vercel에 올리기

제공한 ZIP 안의 `index.html`, `app.js`, `scene.js`, `water.js`, `buildings.js`, `world-photos.js`, `cases.js`, `curriculum.js`, `model.js`, `actions.js`, `style.css`, `icon.svg`, `vercel.json`, `assets/`를 저장소 최상위에 올립니다. ZIP 파일 자체를 올리는 것이 아니라 압축을 푼 내용을 올립니다.

Vercel에서 해당 저장소를 가져와 Framework Preset을 Other로 선택합니다. 별도 빌드·설치 명령과 환경 변수는 필요 없습니다. 정적 파일 전체를 그대로 배포합니다. 앱은 외부 CDN·원격 JS 라이브러리에 의존하지 않습니다.

이 소스 저장소의 `dist/`에는 같은 배포용 파일이 들어 있습니다. Sites 배포는 `dist/`를 사용하고, 배포 ZIP은 그 내용이 최상위에 오도록 포장합니다.

## 과학 모형을 다루는 범위

- 누적 행동 모형의 수치는 무차원 상대 비교값입니다. 실제 배출량, 온도, 연도, 발생 확률로 해석하지 않습니다.
- 좋은 선택이 이전 배출을 즉시 없애거나 기후를 즉시 원래대로 돌리는 모형이 아닙니다. 어린나무의 흡수 기여에는 성장 지연이 있습니다.
- 두 미래의 가상 그림은 경로의 차이를 보여 주는 설명용입니다. 특정 자동차 이용 한 번이 특정 홍수 한 건을 일으킨다는 뜻이 아닙니다.
- 폭설·한파를 포함한 사건 사례, 지역 차이, 장기 추세를 구별합니다. 모든 현상이 전 세계에서 함께 증가한다고 표시하지 않습니다.
- 수조의 단계는 실제 cm, 연도, 부산 특정 지역의 침수 예측과 연결하지 않습니다. 관찰값은 각 건물 중심의 땅 높이보다 수면이 높을 때 ‘바닥 침수’로 셉니다.
- 해수면 원인은 육지 빙하의 녹음과 해수의 열팽창을 설명합니다. 이미 떠 있던 얼음과 육지 얼음을 구별합니다.

관측 수치의 출처와 사진 라이선스는 앱의 ‘자료·사진 출처’, DATA_SOURCES.md, PHOTO_CREDITS.md에서 확인하세요. 교과서 PDF 자체는 포함하지 않습니다.

## 세계 사례 사진과 건물 선택

세계 사례의 사진을 누르면 원본 비율로 크게 볼 수 있습니다. 중국은 2022년 7·8월의 실제 위성 관측을 비교합니다. 캐나다는 2021년 산불 지역을 2024년에 촬영한 피해 흔적이며, 브라질(2016)·인도(2015)는 교과서 사례와 다른 해의 관련 참고 사진입니다. 이 차이를 사진 바로 아래에 표시합니다.

해수면 실험의 ‘건물 배치’에서 종류를 선택하고 모형의 땅을 누릅니다. 선택한 종류는 바꾸기 전까지 유지됩니다. 건물은 24개까지 배치할 수 있고 넓은 학교 등은 실제 모형의 바닥 면적을 기준으로 겹침을 막습니다. ‘건물 이름’으로 이름 표시를 켜고 끕니다. 배치·선택 종류·이름 표시 설정도 백업에 보존됩니다.

## 04 해수면 상승 실험실

‘해수면 실험’을 열면 첫 장면이 탐구 노트에 담깁니다. 물을 넣거나 빼고 움직임이 멈추면 **장면 기록하기**를 누르세요. 건물을 고른 뒤 땅을 눌러 배치하고 **옮기기**로 높은 땅과 낮은 땅을 비교할 수 있습니다.

**탐구 노트**에서 두 장면의 물높이와 잠긴 건물을 비교하고, 해수면 높이 변화가 누구의 생활에 어떤 영향을 줄지 근거와 함께 씁니다. 추가 질문과 시험 전후 기록도 남길 수 있습니다. 해수면 노트만 PNG로 저장하거나 상단 **탐구 기록**에서 다른 차시와 합쳐 읽고 저장할 수 있습니다. 이전 버전의 통합 앱 백업도 불러올 수 있습니다.
